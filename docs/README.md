## 📝 Documentation Standards

### File Organization
- **Root Level**: Only essential project files (README, CHANGELOG, CLAUDE, SECURITY)
- **docs/**: All other documentation organized by purpose
- **Logical Grouping**: Related documents in appropriate subdirectories

### Naming Conventions
- **UPPERCASE.md**: Important/official documentation
- **lowercase.md**: General guides and instructions
- **kebab-case.md**: Multi-word file names

### Content Standards
- **No Demo Credentials**: All documentation is production-ready
- **Clear Navigation**: Easy to find relevant information
- **Professional Format**: Consistent formatting and structure

This organized structure makes it easy to find what you need and maintains a clean, professional project layout.
